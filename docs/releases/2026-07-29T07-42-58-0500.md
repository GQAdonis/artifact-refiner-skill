# Release Notes - 2026-07-29 07:42:58 -0500

## Release Summary

This `1.4.1` patch release fixes Claude Code plugin and marketplace load
failures discovered after the browser-rendering release. It aligns plugin,
hook, subagent, skill, and MCP configuration with the current Claude Code and
Agent Skills specifications.

## Reproduced Failures

An isolated Claude Code startup identified three repository-level issues:

- `hooks/hooks.json` used an obsolete array-based format, producing
  `expected record, received array`.
- `.mcp.json` referenced the unsupported `${workspaceFolder}` variable.
- After correcting the hook shape, the plugin manifest caused
  `hooks/hooks.json` to load twice because it declared a file that Claude Code
  already discovers at the standard path.

The marketplace also declared version `1.3.0` while the plugin manifest
declared `1.4.0`. Non-strict validation warned about the mismatch and strict
validation rejected it.

## Changes

- Converted hooks to the current event-keyed schema using matcher groups and
  nested hook handlers.
- Removed redundant component paths from `plugin.json`; Claude Code now uses
  standard discovery for `skills/`, `agents/`, and `hooks/hooks.json`.
- Synchronized plugin and marketplace versions at `1.4.1`.
- Added official JSON Schema URLs to both plugin manifests.
- Replaced subagent `allowed_tools` fields with `tools` and current built-in
  tool names.
- Updated the root `SKILL.md` frontmatter to the Agent Skills specification.
- Removed auto-loaded external MCP servers so a marketplace install has no
  startup dependency on credentials, network access, or host binaries.
- Added `.mcp.optional.json.example` for explicit E2B, template-forge, and
  rust-mcp-filesystem configuration using `${CLAUDE_PLUGIN_ROOT}` and
  `${CLAUDE_PROJECT_DIR}`.
- Strengthened `scripts/validate-marketplace.sh` with strict Claude Code
  validation, hook/MCP JSON checks, and plugin/marketplace version matching.
- Added the project-scoped `.prometheus/events.jsonl` lifecycle record to
  version control.
